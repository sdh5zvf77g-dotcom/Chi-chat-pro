# Chit-Chat Pro — 2026 Hybrid Voice Translation

Sophisticated browser prototype matching the full product vision.

## What this version includes

- Premium dark UI with the cartoon HUH? branding
- Online / Offline hybrid toggle (seamless)
- Hold-to-speak real speech recognition
- Live translation (online public APIs + offline phrase packs)
- Mode chips: Face-to-Face · Group · Call · Continuous
- Full 2026 feature showcase panel
- Conversation history
- Settings (auto-speak, latency, vibration, force offline)
- Capability indicators (Sub-second, Privacy, Hybrid, Voice)
- Mobile-first, polished for 2026 standards

## How to run

1. Open `index.html` in **Chrome** or **Edge**
2. Allow microphone
3. Hold the big button → speak → release

## Deploy to GitHub Pages

1. Upload all files in this folder to the root of your repository
2. Settings → Pages → Deploy from branch `main` → / (root)
3. Open the GitHub Pages URL

## Note

This is a high-fidelity prototype of the product vision. 
True continuous streaming, voice cloning, multi-party sessions and phone-call translation require production backends (Gemini Live / Realtime APIs etc.). The core experience, hybrid mode and UI are fully functional.
