## How to use the free voice features

1. Open `index.html` in Chrome or Edge
2. Go to **Settings**
3. Choose a preferred system voice
4. Optionally tap **Record My Voice (3s)** to save a local sample
5. Speak as normal — translations use the best available system voice

The app clearly labels the output as **System Voice**. This is the highest quality possible without a paid voice-cloning service.
